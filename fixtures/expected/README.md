# Expected labels (ground truth)

Hand-written by Ethan from the drawings; never generated by a model. Drawing PDFs live next to this folder
as `fixtures/<set>.pdf` and are gitignored; these JSON files are committed.
`tests/contracts` checks every file here against the contract.

## `<set>.json`: partition types
```json
{
  "set": "demo",
  "pdf": "fixtures/demo.pdf",
  "conditions": [
    {
      "type_tag": "A1",
      "studs": {"size_in": 3.625, "gauge": 20, "spacing_in": 16},
      "layers_each_side": [{"thickness_in": 0.625, "board_type": "type_x"}],
      "sides": 2,
      "fire_rating": 1,
      "ul_assembly": "U419",
      "stc": 50,
      "insulation": "3-1/2\" sound batts",
      "height_ft": null
    }
  ]
}
```
Field rules are the `conditions` contract (`contracts/schemas.py`): decimal inches, integer gauge, `board_type`
from `BOARD_TYPES`, `fire_rating` in hours, `null` when the drawing doesn't say. Accuracy is scored field by
field on stud size, gauge, spacing, layers, board type and fire rating.

## `<set>_sheets.json`: sheet kinds
```json
{"set": "demo", "sheets": [{"page": 1, "sheet_no": "A-101", "kind": "floor_plan"}]}
```
`page` is 1-based across the whole set; `kind` is one of `SHEET_KINDS`.
